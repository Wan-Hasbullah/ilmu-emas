Penjana kod tutorial data

Isi borang, satu entri { id, category, question, answer, keywords, tutorials } dijana serta-merta untuk disalin ke dalam faqData dalam tutorial-data.js.

Ingat: kod yang dijana hanyalah SATU entri berserta koma di hujung ({ ... },). Tampal sebagai item baharu di dalam array faqData. Jika kategori belum wujud, tambah dahulu dalam categories.
