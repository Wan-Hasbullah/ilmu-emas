Penjana kod data

Isi borang, satu entri objek { id, kategori, oleh, petikan, link } dijana serta-merta untuk disalin ke dalam senarai/array data sedia ada.

Ingat: kod yang dijana hanyalah SATU entri objek berserta koma di hujung ({ ... },) — bukan keseluruhan array. Tampal terus sebagai item baharu dalam array data sedia ada anda.

Maklumat data

▼ Cara menulis kandungan
  • Setiap baris ialah satu perenggan (kod <p> dijana auto).
  • ## Subtajuk untuk subtopik utama.
  • ### Subtajuk kecil untuk point bernombor atau subtopik kecil.
  • - item untuk senarai.
  • **tebal** dan *condong* untuk penekanan.
  • --- pada baris sendiri untuk garis pemisah.
