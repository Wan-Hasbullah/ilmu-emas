Penjana kod indeks artikel

Isi borang, satu entri objek { id, title, author, category, summary, path } dijana serta-merta untuk disalin ke dalam senarai/array indeks sedia ada.

Ingat: kod yang dijana hanyalah SATU entri objek berserta koma di hujung ({ ... },) — bukan keseluruhan array. Tampal terus sebagai item baharu dalam array indeks artikel sedia ada anda.
